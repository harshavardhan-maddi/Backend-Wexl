# Hospital Backend – Spring Boot

This is the backend service for the Hospital Management System.
It provides REST APIs for authentication and role-based access.

## Tech Stack
- Java 21
- Spring Boot
- Maven
- REST API
- H2 Database (in-memory)

## Features
- Login API for:
  - Admin
  - Doctor
  - Reception
- Role-based response handling
- RESTful architecture
